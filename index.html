Quickstart

Send your first message in under a minute using a simple POST request.

cURL example POST /v1/chat/completions
curl -X POST https://api.neuraflow.ai/v1/chat/completions \ -H "Authorization: Bearer <API_KEY>" \ -H "Content-Type: application/json" \ -d '{ "model": "neura-chat-1", "messages": [ {"role": "user", "content": "Hello, NeuraFlow!"} ] }'

Key concepts

  • • Models: neura‑chat‑1, neura‑code‑1, neura‑embed‑1
  • • Authentication: Bearer API keys per project
  • • Rate limits: plan‑based with burst protection
  • • Streaming: optional, via Server‑Sent Events
